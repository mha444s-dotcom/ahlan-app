# أصول أيقونات Ahlan المعتمدة

هذا المجلد مصدر الصيانة الحالي للأيقونات الـ86.

- `source/`: ملفات PNG الأصلية عالية الجودة اللازمة لإعادة التصدير أو تعديل الأيقونات مستقبلًا.
- `reference/approved-board.png`: المرجع البصري المعتمد.
- `catalog.json`: أسماء الأيقونات ومعانيها وأوصافها ومرجع التوليد.
- `asset-hashes.json`: بصمات الأصول المعتمدة وصور التطبيق عند التنظيف.
- `verify-files.cjs`: يتحقق من الأصول وأحجام الأيقونات وشفافيتها وسلامة النسخة الاحتياطية الأصلية، دون إنشاء ملفات مؤقتة.
- `prepare-assets.ps1`: يعيد تصدير المقاسات 32 و64 و128 و256 إلى `exports/`. ينشئ تقريرًا في `qa/`. لا ينسخ إلى التطبيق إلا مع الخيار `-Install`.

الأيقونات المستخدمة في التطبيق موجودة في `dist/assets/ahlan-ui-icons/` فقط. حُذفت نسخ `exports/` المطابقة وملفات الدمج المرحلية المكتملة؛ يمكن إعادة إنشاء الصادرات من الأصول عند الحاجة. حالة تنظيف المعاينات ونسخ المراحل القديمة موثقة في `CLEANUP_REPORT.ar.md` بجذر المشروع.

للتحقق من الملفات:

```powershell
node design/approved-icon-system/verify-files.cjs
```

لإعادة التصدير فقط:

```powershell
powershell -NoProfile -File design/approved-icon-system/prepare-assets.ps1
```

لم تُشغّل إعادة التصدير أثناء التنظيف، وحُفظت ملفات الصور الحالية دون تغيير. عند اعتماد أصول جديدة مستقبلًا، حدّث بيان البصمات بعد مراجعة التغيير.
